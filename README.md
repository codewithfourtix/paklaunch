# Paklaunch Lahore

A static chapter homepage for Paklaunch Lahore. The layout uses [South Park Commons](https://www.southparkcommons.com/) as its design reference.

## Run locally

Use Node.js 22.12 or newer.

```sh
npm ci
npm run dev
```

Open [the local preview](http://localhost:5173/). Run `npm run build` to produce the static site in `dist/`.

Chapter copy is in `index.html`. The site draws on [Paklaunch's main site](https://www.paklaunch.com/), [chapters](https://www.paklaunch.com/chapters/), [membership](https://www.paklaunch.com/membership/), and [YouTube channel](https://www.youtube.com/@paklaunch2937). The logo, map, event photos, and video thumbnails come from Paklaunch. The decorative line and cube are original illustrations generated for this homepage.
